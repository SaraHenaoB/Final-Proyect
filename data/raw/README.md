# Datos originales 
 
Este proyecto usa el dataset E-commerce Sales and Customer Analytics 150k de Kaggle: 
https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics 
 
Descarga los 4 archivos y coloca aca con estos nombres exactos: 
- ecommerce_sales_customer_analytics_150k.csv 
- order_items.csv 
- product_catalog.csv 
- customer_master.csv 
- dataset_statistics.csv, opcional, estadisticas resumidas 
 
Estos archivos NO se suben al repositorio, ver gitignore
